# Retro Player Profile avatars

`retro-profile-avatars.png` is an original 5×2 pixel-art sprite sheet generated for this
prototype with the built-in OpenAI image-generation tool on August 17, 2026. The portal
uses CSS background positioning to expose its ten equal tiles as individual avatars.

Final prompt:

> Create exactly ten original retro video-game-inspired character portraits arranged in
> a precise 5-column by 2-row contact sheet: friendly space pilot, pixel wizard, neon
> racing driver, cheerful robot, dungeon knight, cosmic cat, arcade martial artist,
> forest adventurer, tiny dragon, and cassette-futurist hacker. Use polished modern
> pixel-art with chunky 16-bit-era pixels, crisp edges, bold geometric tile backgrounds,
> distinct silhouettes, and a cohesive household-friendly visual language. Exactly one
> centered bust portrait per tile with generous safe padding. No characters or effects
> crossing tile boundaries, no copyrighted characters, no console logos, no text, no
> letters, no numbers, and no watermark.
